# Claude Video Editor Motion (Remotion)

用 **Remotion + React + SVG** 复刻的 30 秒手绘风 2D 动效动画（1280×720, 30fps, 900 帧）：主角「小克」在一条连续的剪辑软件界面中完成写代码启动、拖拽素材、裁切废片、投篮加转场、加花字与 `Ctrl+Z` 撤销、狂拉饱和度爆表回调、一键卡点、导出 99.9% 悬念与最终成片海报定格。

## 为什么「一幕之内」能让整个画面都活跃起来？（设计拆解）

这支片子最大的亮点是**没有生硬的切幕**——全片 30 秒只用一个剪辑软件大画布，却节奏极密、情绪饱满，核心靠 5 个设计手法：

1. **虚拟镜头推拉摇移（Virtual Camera Rig）**：同一画布按动作焦点平滑推拉（`1.0x` 全景 → `1.24x` 左下裁切区 → `1.26x` 居中文字撤销区 → `1.28x` 右侧滑块区 → `1.0x` 卡点全景 → `1.24x` 右上角导出 → `1.0x` 收尾海报），用镜头语言代替传统切屏。
2. **跨面板「橡胶长臂」物理交互**：主角小克站在时间轴上，手臂用全画布 SVG 贝塞尔曲线渲染，直接跨面板去抓素材、挥美工刀、拉右侧滑块、戳右上角导出，把冷冰冰的 UI 变成了有生命的游乐场。
3. **五层联动反馈（Action → Feedback）**：每一次操作都同时触发多处画面响应——例如拉饱和度滑块时，滑块变红写「爆表!!」、手机预览实时过曝、漫画字「饱和度:拉满」炸出、小克眼睛变成晕眩圈圈并冒泡「……太亮了」。
4. **喜剧节拍与反差（Micro-Gags）**：
   - 文件名彩蛋：`小克剪辑_最终版_打死不改(3).mp4`
   - 废片自嘲：`对焦中..` / `这段在发呆 zzz` → 掏美工刀丢垃圾桶 + 磁吸补位
   - 失误撤销：花字少字 → 巨大机械按键 `Ctrl+Z` + 绿色印章 `已修正`
   - 进度条悬念：导出故意卡在 `99.9%` → 小克流汗 `…` → `叮！` 礼花炸开 `BONK!`
5. **从工具界面到情绪海报的收尾过渡**：最后 3 秒编辑器背景淡化退居二线，手机预览放大居中并叠加真实短视频点赞 UI（「拿捏了！」），左侧贴出带胶带的手写便签，完成产品感与情绪感闭环。

## 目录结构

```text
src/
├── index.ts                     # Remotion 入口
├── Root.tsx                     # Composition 注册 (1280x720, 30fps, 900f)
├── constants.ts                 # 配色、9 幕时间轴常量与虚拟镜头 Camera Rig
├── ClaudeEditorMotion.tsx       # 主编排器（9 幕状态机 + 联动逻辑）
└── components/
    ├── SceneArtwork.tsx         # 4 段素材矢量动画（夜景 / 拉面 / 柴犬 / 小克蹦迪）
    ├── ClaudeMascot.tsx         # 小克角色、7 种表情、橡胶长臂、道具与漫画拟声词
    ├── EditorPanels.tsx         # 顶部栏 / 左侧三Tab / 右侧滑块 / 手机预览 / 时间轴
    └── Overlays.tsx             # 终端打字开场 / Ctrl+Z 按键与印章 / 礼花与手写便签
```

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动 Remotion Studio 实时预览与逐帧调试
npm start

# 3. 渲染完整 30 秒 MP4 成片 (1280x720, 30fps)
npm run build

# 4. 仅做 TypeScript 类型检查
npm run typecheck
```

## 渲染输出

默认执行 `npm run build` 将输出到 `out/claude-editor-motion.mp4`。
